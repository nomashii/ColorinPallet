# ColorinPallet

**塗って楽しく人助け！**

ColorinPalletは、色を塗ることでモノクロの世界を彩り、人々を助けていく2Dパズルアクションゲームです。

## ゲーム概要

- **ジャンル：** 2Dパズルアクション
- **開発環境：** Unity
- **開発人数：** 5人
- **開発期間：** 約2か月
- **対応プラットフォーム：** Android（※実際の対応状況に合わせて確認）

## ゲームについて

舞台は、色を失った未来の街。
プレイヤーは絵筆を使って色を塗り、世界に彩りを取り戻しながらステージを攻略します。

## 担当した内容

チーム開発の中で、主に以下の機能の実装・調整を担当しました。

- タイトル画面
- ステージ内のプレイヤー操作
- プレイヤーの色変更機能
- 塗り処理とエフェクト
- パレット機能
- インク残量ゲージ・数値表示UI

担当機能の動作確認や、各機能をゲーム内で連携させるための調整も行いました。

## 使用技術

## 開発を通して学んだこと

チームでゲームを制作する中で、複数の機能を連携させることや、操作性・画面表示を確認しながら調整することの重要性を学びました。
